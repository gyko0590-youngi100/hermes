복면가왕 영상 업로드 · Mac mini 자동 저장

대산공장 복면가왕
동영상 업로드

이 페이지에서 참가자 동영상을 업로드하면 맥미니 폴더에 저장되게 설계했씀돠. 링크만 열면 바로 제출 가능하게 만들었슴돠.

허용 형식.mp4, .mov
권장 길이휴대폰 기준 약 1분 내외 영상
파일명 규칙업로드시간_참가자명 또는 팀명
공개 방식링크만 공유, 누구나 업로드 가능
1. 링크 열기참가자에게 이 주소를 전달합니다.
2. 정보 입력이름 또는 팀명은 필수입니다.
3. 파일 선택mp4 또는 mov 영상 파일을 업로드합니다.
4. 자동 저장서버(Mac mini) 폴더로 바로 저장됩니다.
업로드 시 참가자명 또는 팀명을 반드시 입력해 주세요. 파일명은 업로드 시간과 입력값을 조합해 저장합니다.
주의: 실제 저장을 하려면 맥미니에서 업로드 수신 서버가 실행 중이어야 합니다. 아래 server.py를 같이 사용하세요.
권장 파일명 예시: 2026-06-09_1430_혁신1팀.mov
